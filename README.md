# jGestãoSus — instaladores

Instaladores e atualizações do **jGestãoSus** (JEOS Sistemas).

- Baixe o instalador mais recente em [Releases](https://github.com/taylanitallo/jGestaoSus-releases/releases/latest).
- O programa instalado verifica este repositório e avisa quando houver versão nova (*Buscar atualização*).
- Os dados ficam no computador, em `C:\ProgramData\JEOS\jGestaoSus`, e não são apagados ao atualizar.

O código-fonte é privado.
